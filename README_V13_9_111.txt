Santa Clara ERP V13.9.111

Corrección de validación del punto de expedición al facturar.
- La venta usa exactamente el ID seleccionado en pantalla.
- La validación y el selector comparten la misma interpretación de flags Activo / DNIT / FE.
- Compatibilidad con flags históricos almacenados como texto.
- Si un punto no es válido, el mensaje identifica el código y el flag faltante.
- No se sustituyen puntos por Recepción o por el predeterminado cuando el usuario seleccionó uno.
