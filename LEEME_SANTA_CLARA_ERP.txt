SANTA CLARA ERP
Centro Médico Santa Clara / Grupo Santa Clara S.A.
Base funcional: Nextsys (PowerBuilder compilado)

ESTRUCTURA
- Se conserva nextsys.exe como ejecutable técnico original para evitar romper referencias internas.
- Iniciar con INICIAR_SANTA_CLARA_ERP.bat.
- Se conservaron todos los módulos PBD presentes en la distribución operativa más completa analizada.
- Se conservaron runtimes y dependencias PowerBuilder, SIFEN, QR, PDF/Excel, OLE DB y demás bibliotecas encontradas.
- Se conserva bd.ini porque contiene la configuración de conexión requerida por la aplicación existente.
- Se conserva imagen/SANTACLARA.jpg y los recursos SIFEN de Santa Clara encontrados en el paquete original.

FUNCIONALIDAD DETECTADA EN LOS BINARIOS
El análisis de objetos compilados encontró, entre otros, clientes, proveedores, compras,
ventas, facturación, notas de crédito, stock/inventario, códigos de barras, cajas,
cuentas/créditos/cobros, contabilidad, informes, usuarios, grupos, permisos,
auditoría, farmacia, urgencias, quirófano y configuración de sanatorio, además de SIFEN.
El archivo INVENTARIO_OBJETOS_NEXTSYS.txt conserva el inventario de objetos recuperables
por inspección del ejecutable.

BASE DE DATOS
La aplicación no incluye en estos ZIP una copia del SQL Server "nextsys". bd.ini apunta a
una instancia SQL Server externa. Por eso el paquete puede verificarse estructuralmente,
pero las pruebas funcionales que requieren login, maestros, ventas, SIFEN en línea o datos
reales dependen de esa base SQL Server y de la red/credenciales del entorno Santa Clara.
No se cambió el nombre técnico de la base para no inutilizar la aplicación.

IMPORTANTE SOBRE COMPILACIÓN
Los ZIP entregados contienen ejecutables/PBD compilados, no el código fuente PowerBuilder
(PBL/PBT/PBW/SRU/SRW/SRM/SRD). Por tanto no existe material fuente suficiente para
recompilar legal/técnicamente el ejecutable desde cero. Esta reconstrucción conserva la
compilación operativa más reciente encontrada y valida su integridad binaria y sus módulos.
Para modificar ventanas/lógica interna y recompilar, se necesita el proyecto fuente original
PowerBuilder o reconstruir esos módulos como una nueva aplicación.
